# JobMatch — Frontend

Веб-интерфейс JobMatch — сервиса поиска работы с ограниченным количеством откликов.

## Ответственность

- Каталог, поиск, фильтры и карточка вакансии.
- Регистрация и вход.
- Резюме, кабинет соискателя, отклики и остаток лимита.
- Кабинет работодателя, компания, вакансии и обработка заявок.
- UI-компоненты, адаптивность, запросы к API и отображение ошибок.
- Контейнер frontend, Nginx и проверки сборки.

Бизнес-правила и списание лимита проверяет backend.

## Команда

- **Влад** — frontend, UI/UX; интерфейс соискателя и общие компоненты.
- **Игорь** — frontend, DevOps; кабинет работодателя и окружение frontend.
- **Клим** — тимлид; интеграция и техническое ревью.

## Планируемый стек

React, TypeScript, Vite, React Router, TanStack Query, Material UI.
Стек предлагается для утверждения на первом созвоне.

## Текущий статус

Репозиторий подготовлен для начала разработки. Исходного приложения, Dockerfile и CI пока нет; команды запуска появятся вместе с рабочим каркасом.

Ко второй лабораторной: запускаемый React-проект, обращение к API и первичные экраны. К третьей: интерфейс всех согласованных сценариев MVP.

## Связанные репозитории

- [Backend](https://github.com/CODEXSQUAD/jobmatch-backend) — API, БД и совместный запуск.
- [Docs](https://github.com/CODEXSQUAD/jobmatch-docs) — требования, API-контракты, макеты и roadmap.

## Работа с задачами

Задача содержит ответственного, срок и критерий готовности. Изменения выполняются в отдельной ветке и проходят PR с ревью другого участника. В PR указываются связанные задачи и способ проверки.
